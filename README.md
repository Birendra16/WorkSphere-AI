# FlowBoard AI

A production-ready Full Stack Task Management application.

## Tech Stack

- React
- TypeScript
- Express
- MongoDB
- Redis
- Socket.IO

## Project Structure

apps/
packages/
docs/

## Getting Started

```bash
npm install

npm run dev
```
